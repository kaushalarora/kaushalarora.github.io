# Kaushal Arora Portfolio — 8 years experience

Responsive single-page portfolio built with plain HTML/CSS (no build step required).

## Preview
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in at https://github.com/ and create a repository named `YOUR-GITHUB-USERNAME.github.io` (replace with your actual username).
2. Upload `index.html` to the repository root and commit it.
3. Open repository **Settings → Pages**.
4. Under build/deployment, choose deployment from a branch, select `main` and `/ (root)`, then save if those controls appear.
5. After deployment, visit `https://YOUR-GITHUB-USERNAME.github.io/`.

Important: `https://github.com/` is the GitHub homepage, not a personal profile URL. Replace the GitHub button URL in `index.html` with `https://github.com/YOUR-USERNAME` once you know your username.
